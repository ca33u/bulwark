# Bulwark

Аддон прот-паладина для **World of Warcraft: Forever** (Interface 16001). Студия **addicted** — [addicted.sh](https://addicted.sh), лицензия MIT.

Версия 2.0 — полностью своё ядро, написанное с нуля: линия баффов, кулдауны, напоминания, свинг-таймер, окна готовности и статов, настройки. Старые настройки (`BulwarkDB` из 1.x) подхватываются сами при первом входе.

## Что показывает

- **Линия длительности.** Иконки коротких баффов (печати, Righteous Fury, Holy Shield, Consecration, Divine Protection, Divine Shield, Blessing of Protection/Freedom, а также Seal of Fury, Templar's Bulwark, Iron Creed и Shieldsworn из Forever) появляются у начала линии, едут к красному концу и исчезают, когда бафф кончился. Под иконкой — секунды, по желанию — название; в последние секунды иконка мигает. Печати взаимоисключающие. Righteous Fury по умолчанию появляется только в последние 30 секунд. Четыре стиля линии (классический скруглённый, минимальный плоский, утопленная рельса, светящийся со скосом), свои цвета линии, свечения, фона и концов, пресеты.
- **Свинг-таймер.** Тонкая рельса под линией: заполняется между ударами основной рукой, справа — секунды до следующего удара. Источники — `PLAYER_SWING` (если есть) и собственные удары из combat log (можно выключить). Смена оружия перезапускает таймер, выключение автоатаки гасит. Парирование ускоряет следующий удар по классическому правилу (минус 40 % скорости оружия, но не ниже 20 %).
- **Способности** над линией: иконки показываются, только если способность изучена. На кулдауне — тёмные, с «часами» и секундами. Кулдауны учитывают таланты (Improved Judgement, Shieldsworn, Sacred Duty, Guardian's Favor, Improved Hammer of Justice, Purifying Power). Пока висит Forbearance, иммунитеты помечены как заблокированные.
- **Напоминания** красным текстом: «Righteous Fury missing», «Seal missing» / «Seal timer expired», «No aura active» (на вас нет вообще никакой ауры паладина; любая аура — Благочестие, Воздаяние, Сосредоточение, сопротивления — считается); значки Righteous Fury и Forbearance, которые можно перетащить. Звук, когда Seal of Fury спадает в бою. Напоминание появляется только когда аддон уверен: скрытое игрой значение напоминаний не создаёт.
- **Окно готовности танка** (`/bulwark prep`): Righteous Fury, печать, аура, благословение, бафы классов, которые есть в группе, Forbearance, оружие и щит, чары, Subtlety на плаще, еда, настойки и эликсиры, защита. Зелёный — хорошо, жёлтый — не удалось прочитать или совет, красный — не хватает.
- **Окно статов смягчения** (`/bulwark mitig`): промах, уклонение, парирование, избегание, блок, шанс крита (и сколько защиты нужно до иммунитета), сокрушающие удары (и сколько не хватает до 102.4 %), показатель блока, броня и её снижение урона, эффективное здоровье, сила заклинаний, меткость — против рейдового босса (или выбранного уровня).
- **Список агро** (`Aggro.lua`). Панель с мобами в бою вокруг вас, по вражеским nameplate (они должны быть включены, клавиша V). Золотой — бьёт вас, оранжевый — вот-вот уйдёт на другого, красный — «свободный»: в бою с группой, но бьёт не вас (справа видно, кого). Свободные сверху. Если клиент скрывает угрозу моба, строка серая.
- **Обновление рангов** (`Ranks.lua`). Выучили новый ранг — все кнопки на панелях с прежним старшим рангом заменяются новым. Даунранк не трогается. В бою замена ждёт конца боя.
- **Окраска неймплейтов** (`Plates.lua`) по угрозе: зелёный — держите, оранжевый — теряете, красный — ушёл.
- **Благословения группы** (`Blessings.lua`). Маленькие иконки благословений паладинов справа от рамок группы, под иконкой — сколько минут осталось. Золотая рамка — ваше, серая — чужое, красный крестик — благословения нет.
- **Мало маны в группе** (`PartyMana.lua`). Полоска маны участника с маной ниже порога (по умолчанию 30 %) накрывается красной пульсирующей подложкой.

Все чтения значений, которые WoW Forever прячет в бою (secret values), идут через guard'ы: скрытое значение не ломает аддон, а оставляет последнее прочитанное. Рамки Blizzard не трогаются; запрещённые (forbidden) рамки даже не читаются.

На других классах паладинские части скрыты, модули (агро, неймплейты, ранги, благословения, мана) работают.

## Установка

Скачайте `Bulwark-2.3.0.zip` и распакуйте в `World of Warcraft/_forever_/Interface/AddOns`.

Из исходников (`~/Develop/Bulwark`):

```
~/Develop/Bulwark/install.sh
```

Потом в игре `/reload`. Если аддона нет в списке, выйдите на экран выбора персонажа и зайдите снова. `./package.sh` собирает архив в `dist/`.

## Команды

`/bulwark` или `/bul`

| Команда | Что делает |
|---|---|
| `/bulwark` | список команд |
| `/bulwark unlock` (`move`) | разблокировать: линию, группу способностей, текст напоминаний и значки можно таскать мышью |
| `/bulwark lock` | заблокировать обратно |
| `/bulwark options` | окно настроек (вкладки Bar, Abilities, Warnings, Swing, Mitigation, About); то же — правый клик по разблокированной линии, кнопка у миникарты или список аддонов |
| `/bulwark scale 1.2` | масштаб линии (0.6–2) |
| `/bulwark width 500` | длина линии (200–800) |
| `/bulwark thick 8` | толщина линии (2–24) |
| `/bulwark readysize 32` | размер иконок способностей (12–64) |
| `/bulwark readyx 0`, `/bulwark readyy 50` | сдвиг группы способностей от линии |
| `/bulwark readygap 4` | интервал между иконками (0–24) |
| `/bulwark timers` | секунды под иконками вкл/выкл |
| `/bulwark names` | названия под иконками вкл/выкл |
| `/bulwark swing` | показать/скрыть свинг-таймер |
| `/bulwark swingheight 5` | толщина рельсы свинг-таймера (2–12) |
| `/bulwark swinggap 6` | отступ рельсы от линии (0–60) |
| `/bulwark swinglog` | включить/выключить источник из combat log |
| `/bulwark swingdebug` | что питает таймер автоатаки: приходят ли события ударов, какая скорость оружия |
| `/bulwark warnings` | включить/выключить все напоминания разом |
| `/bulwark combat` | все элементы только в бою |
| `/bulwark test` | тестовые иконки, напоминания и свинг-таймер на 12 секунд |
| `/bulwark reset` | вернуть положение и размеры по умолчанию |
| `/bulwark prep` | окно готовности танка |
| `/bulwark mitig` | окно статов смягчения |
| `/bulwark spellcheck` | почему горят напоминания: видит ли аддон Devotion Aura, Righteous Fury и печати по ID и в книге заклинаний |
| `/bulwark debug` | что сейчас отслеживается |
| `/bulwark aggro` | показать/скрыть список агро |
| `/bulwark aggrocombat` | список агро только в бою (вкл. по умолчанию) |
| `/bulwark plates` | окраска неймплейтов по угрозе вкл/выкл |
| `/bulwark platesreset` | вернуть настройки неймплейтов к стандартным |
| `/bulwark blessings` | благословения группы целиком вкл/выкл |
| `/bulwark blessingsframes` | иконки у рамок группы (вкл. по умолчанию) |
| `/bulwark blessingspanel` | отдельная панель со строками (выкл. по умолчанию) |
| `/bulwark blessingssolo` | показывать благословения и без группы |
| `/bulwark classicons` | иконка класса перед благословениями у рамок группы (по умолчанию вкл.); если благословения нет, серым показано нужное: Могущество воинам и разбойникам, Мудрость остальным |
| `/bulwark blessingsdebug` | какие рамки группы нашёл аддон |
| `/bulwark lowmana` | подсветка малой маны у группы вкл/выкл |
| `/bulwark lowmana 25` | порог подсветки в процентах (5–90) |
| `/bulwark ranks` | сразу заменить все младшие ранги на панелях старшими |
| `/bulwark autoranks` | автозамена рангов вкл/выкл |
| `/bulwark rankscheck` | какие заклинания с рангами стоят на панелях и какой ранг должен быть |
| `/bulwark keepdownranks` | не трогать младшие ранги, поставленные специально (для лекарей) |

Разблокированная линия: колесо — масштаб, Shift+колесо — длина, Alt+колесо — толщина, правый клик — настройки. Группа способностей: колесо — размер иконок, Shift+колесо — интервал.

## Как это устроено

- `Locales/` — переводы (английский — исходный, плюс ruRU, deDE, frFR, esES/esMX, ptBR, koKR, zhTW).
- `Core/` — ядро по разделам: `Init` (события, `Bulwark.SetLocked`, slash), `Guards` (secret values, forbidden-рамки), `DB` (настройки и перенос из 1.x), `Spells` (каталог, книга заклинаний, таланты), `Auras`, `Line`, `Swing`, `Abilities`, `Reminders`, `Prep`, `Mitigation`, `Options`, `Minimap`, `Movers`, `Slash`, `Boot`.
- `Aggro.lua`, `Ranks.lua`, `Plates.lua`, `Blessings.lua`, `PartyMana.lua` — модули.
- Линия, свечение и рельса рисуются обычными текстурами, своих картинок нет; иконка — встроенная `INV_Shield_06`.
- `tests/run.sh` — тесты на обычном Lua (`brew install lua`).

Заклинания узнаются по ID, затем по названию. ID заклинаний Forever (Seal of Fury, Holy Strike, Templar's Bulwark…) аддон запоминает сам — из книги заклинаний, ваших кастов и аур (`BulwarkDB.learnedIDs`).
